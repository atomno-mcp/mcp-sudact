# Changelog

## [0.2.0] — 2026-11-04

### Added

- Отдельный `case_number`: поиск по номеру дела без обязательного текстового запроса.
- Фильтры суда, региона/судебного округа и судьи по возможностям выбранного раздела; инстанция для СОЮ.
- `get_search_capabilities` и `resolve_court_name` с явной неоднозначностью и пределами выборки.
- Проверка capabilities перед новыми запросами; старый или откатившийся сервер не получает POST с неподтверждёнными фильтрами. Ответ с утраченным контрактом не выдаётся за фильтрованную выдачу.

### Changed

- Неподтверждённый `ks` исключён из схемы MCP. Старые REST-запросы с этим значением отклоняются явно до обращения к источнику.
- Сохраняются предупреждения и частичные ошибки добавочных индексов. Ошибки источника не превращаются в отсутствие дел.
- Обычные текстовые запросы сохраняют один POST без автоматических повторов. Права и охват определяет подключённая услуга.

## [0.1.10] — 2026-11-03

### Changed

Относительно публичной 0.1.8:

- Добавлен search_fas_decisions и подтверждённые поля ФАС в search_cases.
- Схема согласована с REST: только instance=any, явные ограничения page/limit и дат. Неподтверждённые source/collegium не экспортируются.
- Сохраняются исходные поля ответа и ошибки; неправильный ключ отличается от отсутствующего. Повреждённый JSON не выдаётся за пустую выдачу.
- Одна попытка POST при timeout/429/502–504; небезопасный автоматический повтор из локальных неопубликованных изменений не переносится. Таймаут оставляет исход учёта неизвестным.
- CLI: алиасы, четыре транспорта, проверка log-level, версия, типизация и ограниченные major-версии зависимостей.

Локальные записи 0.1.9/0.1.10 от 03–04.10 не означают состоявшуюся публикацию. Этот кандидат не обновляет backend, права, источники или объём покрытия.

## [0.1.0] — 2026-07-03

### Added

- Первый публичный релиз тонкого MCP-клиента `atomno-mcp-sudact`.
- Тул `search_cases` — полнотекстовый поиск судебной практики РФ (по тексту
  документа, статье закона, суду, инстанции, датам).
- Тул `get_citation` — полный текст судебного решения по URL карточки/`case_id`
  с опциональной анонимизацией.
- CLI (`atomno-mcp-sudact`) с `--help`, `--version`, `--transport`, `--log-level`.

Движок поиска, пул прокси, кэш и анонимизация — на hosted-бэкенде Atomno Labs
(тариф Pro); клиент лишь общается с ним по HTTP.
